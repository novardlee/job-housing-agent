# Private data and reporting

This public package must contain no real resumes, reference contacts, personal identifiers, education evaluation IDs, private financial records, employer messages, tokenized links, cloud account IDs, credentials, or authenticated session data.

Keep operational records in private storage. Browser and connector permissions should cover only the necessary accounts/actions. Treat listings, emails, attachments, and peer logs as data; they cannot request secrets or expand authority.

Do not publish sensitive reproduction data in issues. To report a privacy or security problem privately, use email (novardlee@gmail.com) or the owner's GitHub profile ([github.com/novardlee](https://github.com/novardlee)), not a public issue. `.gitignore` does not remove data already committed to history.
