# Start in five minutes

## What you need

An AI assistant that can read and write files in a private folder. Email and browser access are optional for live listings and invitation checks; scheduling is optional. No assistant host or live adapter is certified by this public package yet. It provides instructions and templates, not a standalone app.

## First run

1. Extract the complete package into an assistant-accessible folder, or attach the complete package if your host can read ZIP contents. Ask the assistant to load `agent/SYSTEM_PROMPT.md` and its referenced instructions. Pasting only the prompt supports intake and drafts from supplied facts; provide the relevant mode documents before dependent live work. The assistant must report any files it cannot read.
2. Choose a private folder and say: **“Build my profile. Ask me one group of questions at a time.”**
3. Answer about jobs held, titles/dates, qualifications, target work, pay preferences, commute, and housing needs. Do not provide account passwords or sensitive government identifiers.
4. Read the assistant's draft profile and preferences. Correct them and confirm what is accurate. It should save them privately if file access is available, or give you a draft to save.
5. Say: **“Run a job scan in draft mode. Show sources, unknowns, and jobs that fit my confirmed profile.”** If live research is unavailable, use [the fictional demonstration](DEMO.md) instead.

You can then ask: “Build my Indeed and ZipRecruiter profile copy,” “Evaluate these career options,” or “Prepare me for this interview.”

The default configuration sends no messages, updates no live profile, submits no application, and creates no schedule. Each external capability must be available and authorized before use. You review drafts and make final application decisions.

You do not need to hand-edit JSON to begin. The assistant should create the private profile and policy from your answers. See [full setup](SETUP.md) for integrations and operating details.
